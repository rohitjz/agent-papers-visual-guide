# Agent papers visual guide

An interactive, first-principles guide to ten foundational AI agent papers.

**[Open the live guide](https://rohitjz.github.io/agent-papers-visual-guide/)**

Start with "What makes an agent?", work through the paper lessons, then use
"Connect & practice" to compare mechanisms and test your understanding.
Demonstrations are authored teaching simulations, not live model runs.
Original paper links are included in each lesson.

## Run locally

Download [index.html](./index.html) and open it in a browser. The guide is
self-contained and works offline. Knowledge-check progress is encoded in
the URL rather than stored in a browser profile.

## Publishing

GitHub Pages publishes from the root of the `main` branch over HTTPS.
The live homepage is [index.html](./index.html). Update that file to change
the live guide; pushes to `main` trigger a new Pages deployment.

The original upload, [agent-papers-visual-guide.html](./agent-papers-visual-guide.html),
is retained so existing file links continue to work. If both entry points
should show the latest guide, update both HTML files together.
